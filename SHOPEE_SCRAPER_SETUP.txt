🎯 WHAT IT DOES
════════════════════════════════════════════════════════════════════════════════

Scrapes from: https://shopee.com.my/

Extracts:
  ✓ Product Name (e.g., "Samsung Galaxy S24 Ultra")
  ✓ Product Price (e.g., "RM 5,999")
  ✓ Product Image (e.g., "https://cf.shopee.com.my/...")
  ✓ Product Link (e.g., "https://shopee.com.my/...")

Limits:
  • Maximum 10 products per request (configurable)
  • 60-second timeout
  • Handles JavaScript content
  • Automatic error recovery

📋 ONE-TIME SETUP (Installation)

Run These Commands Once:

1. Install Python dependencies:
   $ pip install -r requirements.txt

💻 HOW TO USE
════════════════════════════════════════════════════════════════════════════════

EASIEST WAY:
   $ python scrape_shopee_now.py
   
   This runs setup checks and scrapes automatically!

MANUAL WAY:
   $ python check_shopee_setup.py  # Verify setup
   $ python scrapers/shopee_firecrawl_scraper.py  # Run scraper

PYTHON CODE:
   import asyncio
   from scrapers.shopee_firecrawl_scraper import ShopeeScraper
   
   async def main():
       scraper = ShopeeScraper()
       products = await scraper.scrape_shopee_homepage()
       for p in products:
           print(f"{p['name']} - RM {p['price']}")
   
   asyncio.run(main())

🎓 EXAMPLES
════════════════════════════════════════════════════════════════════════════════

Example 1: Search for specific products
   products = await scraper.scrape_shopee_search(
       query="laptop",
       limit=10
   )

Example 2: Filter by price
   products = await scraper.scrape_shopee_homepage()
   affordable = [p for p in products if float(p['price']) < 1000]

Example 3: Export to CSV
   import csv, json
   
   with open('shopee_products.json') as f:
       products = json.load(f)
   
   with open('shopee_products.csv', 'w') as f:
       w = csv.DictWriter(f, fieldnames=['name', 'price', 'image_url'])
       w.writeheader()
       w.writerows(products)

Example 4: Download images
   import requests
   
   for p in products:
       r = requests.get(p['image_url'])
       with open(f"images/{p['name']}.jpg", 'wb') as f:
           f.write(r.content)
