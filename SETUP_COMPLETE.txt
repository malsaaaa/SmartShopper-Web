🎯 THREE POWERFUL TOOLS
═══════════════════════════════════════════════════════════════════════════════

🔹 CRAWL - Extract full page content with Markdown
   • Extracts HTML, text, Markdown
   • Auto-converts to Markdown format
   • Extracts links and metadata
   
   Usage:
   result = await client.crawl("https://example.com")

🔹 SCRAPE - Extract structured data with schema
   • Define extraction schema in JSON
   • Flexible field mapping
   • Clean structured output
   
   Usage:
   result = await client.scrape(url, {"name": "h2", "price": "span"})

🔹 EXTRACT - Extract with CSS selectors
   • Simple CSS selector queries
   • Multiple selectors support
   • Direct content extraction
   
   Usage:
   result = await client.extract(url, ["h1", "p", ".price"])

📝 USAGE EXAMPLES
═══════════════════════════════════════════════════════════════════════════════

EXAMPLE 1: Crawl and Get Markdown
   import asyncio
   from firecrawl_mcp_server import FirecrawlMCPServer
   
   async def main():
       server = FirecrawlMCPServer()
       result = await server.client.crawl("https://example.com")
       print(result.markdown)
   
   asyncio.run(main())

EXAMPLE 2: Extract Product Info
   result = await client.extract(
       "https://shop.example.com/product",
       ["h1.title", "span.price", "div.rating"]
   )
   print(result["data"])

EXAMPLE 3: Scrape with Schema
   schema = {
       "products": "div.product",
       "titles": "h2.name",
       "prices": "span.price"
   }
   result = await client.scrape("https://shop.example.com", schema)

EXAMPLE 4: CLI Usage
   node firecrawl_mcp_client.js crawl \
     --url https://example.com \
     --output result.json \
     --pretty
